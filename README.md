# Anukarsh C - Developer Portfolio & AI Certificate Hub

A modern, responsive personal portfolio and achievement showcase for **Anukarsh C**, Aspiring Full Stack Software Engineer specializing in Python, Backend Architecture, Database Systems, and AI integrations.

## 🚀 Key Features

- **Dynamic Interactive Design**: Dark/light theme toggle, smooth micro-animations (GSAP & ScrollTrigger), interactive particle canvas background, and custom cursor.
- **AI-Powered Certificate Scanner**: Upload certificate images or PDFs; client-side OCR and NLP analyze documents in real-time, automatically extracting titles, issuing authorities, categories, dates, and synthesizing descriptions.
- **Client-Side Storage**: Permanent offline-capable storage powered by IndexedDB with localStorage fallback for custom uploaded certificates.
- **Lightbox Viewer**: Preview certificates and achievement documents directly within the app, supporting high-resolution images and embedded PDFs with download options.
- **Category Filtering & Stats**: Real-time counter updates and filtering across internships, elite academic credentials, workshops, and achievements.

## 📁 Project Structure

```
├── certificates/         # Existing certificate assets
├── index.html            # Core application layout & markup
├── style.css             # Design system, themes, and animations
├── script.js             # Logic, AI extraction, and IndexedDB storage
├── profile.jpg           # Profile image
└── resume.pdf            # PDF resume
```

## 🛠️ Getting Started Locally

No complex build pipeline required — simply serve statically with any web server:

```bash
# Using Python
python -m http.server 8000

# Open in browser
http://localhost:8000
```
